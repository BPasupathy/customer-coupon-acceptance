# Dataset

The original `in-vehicle-coupon-recommendation.csv` is distributed by the UCI Machine Learning Repository under CC BY 4.0.

Official page: https://archive.ics.uci.edu/dataset/603/in+vehicle+coupon+recommendation  
Direct CSV: https://archive.ics.uci.edu/ml/machine-learning-databases/00603/in-vehicle-coupon-recommendation.csv

The notebook downloads the source file to this directory as `coupons.csv` when it is not present. The raw data is not duplicated in this repository; retrieve it from UCI so the provenance and license remain clear.
